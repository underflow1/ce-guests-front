Design System

Единая система визуальных токенов и компонентов для десктоп-приложений. Все стили строятся на foundations.

Полный демо

Главный экран приложения: грид виджетов на фоне, окно поверх. Клик по имени — меню пользователя. Перетащи окно за заголовок.

Тема: Backlog — управление задачами. Карточки, панели, таблица, форма в окне.

Типографика в демо: заголовки карточек/панелей — .text--bold; заголовок окна — .text--up .text--bold; основной текст — .text; второстепенный (мета, автор) — .text--muted; подписи — .text--down.
